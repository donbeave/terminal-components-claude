These documents contain synthesized ideas, not instructions to reproduce a
specific product. They start from Holla's intended user needs and experience.

Everything here is conceptual context. No document defines screen layout,
styling, component form, control placement, visual hierarchy, exact key binding,
or required interaction rendering. Future design work must explore and choose
those independently.
