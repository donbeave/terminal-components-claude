## Coverage traps to carry into parity matrix

1. **Mise != package.json/Just/Make/Taskfile**. Only mise task structs/catalog exist; fixture `pnpm test` as task command is not manifest discovery.
2. **Systemd != brew services**. Only production systemd status/journal/restart; no brew start/stop/restart equivalent.
3. **Upgrade everything != all old upgrade providers**. Apt+mise fixture graph only.
4. **Disk page != disk tree**. Flat categories, facts drawer, candidates-only selection, no path filtering/drilldown/noise folding.
5. **Trash label != Trash defaults/recovery/free-space outcome**. Fixed method, no mode choice/restore, used space decremented same as permanent.
6. **Two gates != path safety validator**. Boolean protected fixture and literal safety text don't cover invalid/canonical/symlink/race/mount cases.
7. **Attached != stdin**. Ordinary attached keys consumed; task kinds never attachable.
8. **Generic success != operational state parity**. Especially single Docker destructive variants and disk.delete_all.
9. **Trust page != compatible custom action/config contract**. In-session path list, no digest/global/project parser/argv surface.
10. **Passing narrow effect test != all finished actions truthful**. Current test only proves cleanup plan and PG cancel; Docker plan separately tested. README blanket truth claim overstates effect coverage.
11. **Mise outdated upgrade loop**. Outdated snapshot follow-up opens same action/snapshot; standalone upgrade not accomplished.
12. **Active today never selected overclaim**. Only initial defaults exclude it; user Space/a can select recent items if otherwise eligible. Need explicit intended policy decision.
