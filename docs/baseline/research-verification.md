## What changed since the research (`5036cf8` → `263eeeb`, 12 commits)

- **`7d5d62c` "preserve canonical terminal attributes and geometry"** — the big one for the claims: adds `hidden`/`blink` to `Mods`, flips claim 2 from true to outdated. Frame schema is now v3 (`src/frame.rs:22`; fixtures migrated in `02102e9`).
- **`e45d3fa` / `883d03f`** — physical cursor exposure without discarding pending wrap; canonical-capture repairs made reusable.
- **`fc4b5f4` + `350f340`** — raw-replay engine swapped from the `vt100` fork to `termpane` (pty feature is now `termlens` + `termpane`; at the pin it was `termlens` + `vt100`, cf. `5036cf8:Cargo.toml:21,36`). The `Session` API surface itself is unchanged since the pin.
- **`263eeeb` (HEAD)** — rendering-only commit; gate semantics, frame schema, fail-closed/accept contract explicitly unchanged (commit message + diff verified):
  - HiDPI-native rasterization: glyphs rasterized at `font_px * scale` directly (`src/render.rs:340-346`); the old 2× nearest-neighbor upscale is gone.
  - Default family DejaVuSansM NFM → **JetBrainsMono Nerd Font Mono**, 4 real faces (`src/profile.rs:32-70`, `VENDORED_FACES`); real bold/italic replace faux double-strike/shear, which survive only as parse-failure fallback recorded in `fell_back` (`src/render.rs:99-116`, `:254-294`).
  - Cell metrics re-pinned 10×19 → **10×21** at `font_px 16`, `scale 2` (`src/profile.rs:103-113`); `verify_geometry` still pins unscaled metrics (`src/render.rs:74-83`).
  - `.png.fidelity.json` sidecars: missing glyphs + `faces_fell_back` reported next to every PNG, mirrored to `approved/` on accept (`src/render.rs:129-160`, `src/snapshot.rs:329-332`, `:492-499`).
  - Standalone `--format html`: selectable run-coalesced SVG primary (`src/render.rs:488-584`), authoritative PNG under `<details>` (`src/main.rs:188-207`).
  - API break vs the pin: `render_png`/`Store::check` now take `&FontFaces` instead of `&[u8]`; new `render_png_report` returns `{png, fidelity}` (`src/render.rs:317-331`).

## Migration-relevant API surface (authoritative answer for the follow-on Rust integration-test suite)

### What `tuisnap::pty` gives a Rust suite driving app binaries (feature `pty`, on by default)

Everything the CLI `--send` DSL does, from the library:

| DSL step (`--send`/`run_once`) | Library equivalent | Location |
|---|---|---|
| bare key name (`enter`, `esc`, `tab`, `backtab`, `up`…, `space`, `f1..f12`, `ctrl-x`, `alt-x`, single chars, `text:<literal>`) | `Session::send_key` | `src/pty.rs:172-208` |
| `type:<text>` | `Session::type_text` | `src/pty.rs:211-213` |
| `sleep:<ms>` | `std::thread::sleep` (no wrapper needed) | `src/pty.rs:298-300` |
| `wait:<needle>` | `Session::wait_for_text` (fails on timeout, error embeds the screen) | `src/pty.rs:256-258` |
| (DSL runner itself) | `pub fn run_once(argv, opts, sends, settle)` — the parser **is** exposed | `src/pty.rs:289-313` |
| beyond the DSL | `wait_stable` (style-aware, returns `Frame`), `wait_idle`, `wait_exit`, `snapshot`, `paste`, `paste_literal`, `click`, `drag`, `resize` | `src/pty.rs:165-275` |

Library-only vs CLI: `click`/`drag`/`resize`/`paste`/`paste_literal`/`wait_exit`/`wait_stable` have **no** CLI flags (`src/main.rs:80-108` exposes only cols/rows/send/wait-for/timeout/settle). CLI-only conveniences: `--wait-for` sugar (`src/main.rs:378-381`), the `report` re-verify sweep + `glob_actual` (`src/main.rs:323-354`, `:415-434`), `--font-file` single-face override glue (`src/main.rs:111-138`; `Profile::with_font_file` itself is library).

### Gaps a Rust suite will hit (precise list)

1. **No custom-predicate wait.** termlens' `wait_until(|screen| …)` is not wrapped and `Session.term` is private (`src/pty.rs:132-133`). Only substring (`wait_for_text`), idle, stable, and exit waits exist. "Wait until text disappears", "wait until cursor at (x,y)", "wait until style X" are impossible without re-building on `tuisnap::termlens` directly (re-exported at `src/lib.rs:31`).
2. **No mouse scroll, no non-left buttons.** termlens has `scroll`/`scroll_with` (`vendor/termlens/src/terminal.rs:2592`,`:2623`) and `click_with(MouseChord)` (`:2493`); tuisnap wraps only left-button `click`/`drag` (`src/pty.rs:238-247`). Scrolling scenarios (very likely in TUIs) are blocked at the tuisnap layer.
3. **`run_once`'s pacing is not composable.** Initial `wait_idle(200ms)` (`src/pty.rs:296`) and the 120 ms post-key/type sleeps (`:305`,`:308`) are baked into the one-shot runner only; a multi-checkpoint scenario driving `Session` manually must add its own settles (or use `wait_stable`, which is stricter and better).
4. **Key-combo ceiling:** `ctrl-`/`alt-` accept exactly one char; no `ctrl-up` style modified special keys (`src/pty.rs:196-205`).
5. **Resize bounded** to 2..=1000 per axis by termlens (`src/pty.rs:249-252`).
6. **Env presets** `TERM`/`COLORTERM`/`LINES`/`COLUMNS` are always set before user env (`src/pty.rs:146-152`); override behavior depends on termlens last-wins semantics — pin this in the suite rather than assuming.
7. **Report assembly is DIY (claim 9):** re-implement `report_entry` (`src/main.rs:229-264`) or accept path-only outcomes; and route around the claim-4 defect (expected panel shows "missing approval" whenever `approved/<name>.png` is absent on disk, even though pixels were gated against an in-memory render — visible as `approved_png_regenerated: bool` on `CompareOutcome`, `src/snapshot.rs:111`).
8. **Font bytes flow through every call:** `Store::check` needs `&Profile` + `&FontFaces` (`src/snapshot.rs:313-320`); use `VENDORED_FACES` (`src/profile.rs:66-71`). No caching exists (claim 6) — a 4-binary suite doing many checks pays 5 font parses per render; consider batching checks per process and expect this on the hot path.

### Store contract for the suite (all verified)

`Store::check` writes actuals before asserting, never mutates `approved/` (only `accept` does), fails closed on missing/corrupt approval, honors an existing approved PNG over re-render, and there is no env-var bless (`src/snapshot.rs:306-465`; tests `tests/snapshot.rs:38-49`,`:137-150`,`:213-228`). This repo's committed `shots/tuisnap/approved/*.png` mean renderer upgrades surface as pixel failures — intended.
