## Authority and stop condition

The complete user task is preserved in [main-holla-integration-task.md](main-holla-integration-task.md).
Main is the implementation base; pinned Holla is the product reference. All four
applications, every surviving architecture obligation, all verification layers,
and exact merged-commit verification are required. Narrow slice acceptance is
never whole-application or whole-goal acceptance.

This supersedes Holla-first/tree-replacement directions in
HOLLA_REFACTOR_RECOVERY_PLAN.md and holla-project/notes/main-vs-holla-refactor-analysis.md,
historical three-app scope, developer-machine defaults and unavailable-model
routing. Their technical findings remain investigation inputs. No reference
defect authorizes unsafe effects, secret disclosure or inaccessible controls.

User requires parallel subagents, signed commits with the Codex co-author
trailer, push, and merge. Merge follows the complete acceptance gates; no failing
or unreviewed candidate is approved merely because a narrow suite passes.
