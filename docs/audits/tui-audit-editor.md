# Editor and Unicode search audit

Scope: current `holla-fable` worktree only. Existing `CodeEditor`, `TextBuffer`, and `ui::text::fuzzy` cover the capability; no new widget or public dependency required. Contract: `DESIGN.md` shared editing rules and Code editor section; existing showcase Editor page, TablePro queries, Holla completion ranking.

## Verification

All new regressions except additive preservation checks were run against the defective implementation first and failed. Focused final checks: `cargo test --lib widgets::code::tests` (10 passed), `cargo test --lib ui::text::tests` (7 passed), `cargo clippy --all-targets -- -D warnings` passed. Owned files formatted with Rustfmt. Root verification owns final repository-wide fmt, complete suite, deterministic scenarios, and captured visual inspection.

No dependencies or new widgets added. Search uses Rust Unicode lowercase semantics, not locale-specific collation, canonical normalization, or Unicode full case folding. Mapping adds a linear source-grapheme index per search; no performance improvement is claimed. Existing widget modules document find-range coordinates, paste ownership, modified Enter, and fuzzy offset semantics.
