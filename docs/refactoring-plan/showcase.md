## Shell, interaction and terminal-size contract

O:src/bin/showcase/app.rs is authoritative for routing. Keyboard navigation owns arrows/j/k/Home/End/g/G/PageUp/PageDown while navigation has focus; movement changes cursor, Enter/Space chooses, Right/l chooses and enters content. Page editing gets keys before global `[`, `]`, `?`, `i`, `0`, `q`; Ctrl+C quits even during editing. Escape exits editing/overlay first, otherwise returns focus to navigation without navigating or quitting. Tab/BackTab form a deterministic cycle and skip disabled/inert/clipped controls. Page state persists when revisiting.

Mouse Move restores hover after keyboard suppression. Record Down and Up separately: a matching completed click activates, release elsewhere cancels. Fields enter editing on completed click; terminal/diff press establishes the selection anchor. Drag remains routed to the original press owner. Wheel is three rows per notch, targets the scroll owner under the pointer even when another widget has focus, consumes boundary wheels and refreshes hover after content moves. Horizontal wheel affects tables/grid/editor. Global dialogs trap focus, block background click/wheel/paste, suspend page ticks and restore prior focus. Page-local menus/pickers/completion retain their exact oracle capture/dismissal behavior; do not presume identical modal rules across these distinct layers.

Sizes **80×24, 100×30, 120×40, 160×50** cover narrow/standard/wide defaults for every page. Additional shell boundaries: 71×20/72×20 and72×19, inspector99/100 columns, sidebar109/110 columns, compact31/32 rows. O has 23 rows plus five section/gap rows: `body.height < 28`, so **terminal height31 is compact, height32 expanded**. This differs from the stale 22-page audit's30/31 transition. Header y0; footer h-1; body y2,h-4; sidebar19 columns below110 else24; main starts sidebar+2; inspector30 columns only when enabled and width≥100, with two-cell gap. Below72×20 show reduced notice; q/Ctrl+C remain supported. Resize checkpoints occur immediately after resize and after the next input/tick, because wrong stale geometry may disappear one frame later.

## Deterministic scenario contract

`showcase-scenarios.tsv` is the normative scenario inventory. It is planning data, **not an invented task-format schema or a claim of captured evidence**. Scenario IDs are stable; task planner assigns owners through its canonical task graph. Every row is required. Parameterized rows expand deterministically as specified here; fixture generation must materialize expansion IDs and reject missing/duplicate cases.

Each scenario starts from a fresh oracle App with fixed fixture data, explicit size/color, no ambient paste/clock/randomness and `goto(page)` before its first render. Defaults use all four sizes × truecolor/256/16/mono (368 page default frames). O exposes Junie only; Paper is a separate accepted architecture/theme gate if the historical ledger requires it, never an invented O app parity oracle.

Every `;` separates a checkpoint: retain the **entire frame** (symbol, foreground, background, modifiers, dimensions, cursor position and visibility), not only text or cropped content. Also retain normalized observable transition facts: route, semantic focus path, hovered/pressed path, edit state/draft/committed value, selection/copy payload, dialog/menu, scroll offsets/follow, pending changes, emitted status and quit. Internal IDs may differ; mapping is semantic and frozen from O, not equality of architecture internals. State probes may observe production state but cannot replace actual key/mouse event routing.

`focus(label)` means replay the **oracle-recorded Tab sequence** from navigation to that named live control. `click/hover/down/up(label)` means use a coordinate resolved once from O's rendered frame/hit metadata and frozen per size/checkpoint. Replaying against M must use that same coordinate and key sequence, never find candidate text/registry to retarget an incorrect layout. For scrolling actions `wheel(target,n)` is n vertical notches at the frozen point, negative up. `drag(target,from,to)` explicitly emits Down, intermediate Drag, Up and captures each; points derive from O's region edges or text-cell anchors. `clear/type` uses Ctrl+U then literal Unicode text; `paste` emits the paste event and its PTY bracketed-paste equivalent. Every target's actual oracle IDs, coordinates, Tab counts and checkpoint hashes must be serialized during the prerequisite trusted baseline acquisition task before downstream parity tasks are ready.

`ticks(n)` sends exactly n production Tick inputs; frame cadence alone must not advance simulation. `time(t)` advances a trusted deterministic clock on the candidate; O's Instant-based deadline evidence requires the verification plan's oracle acquisition/clock seam with provenance. Until that seam is implemented and its equivalence proven, deadline rows remain **required, uncaptured**, not passed. Keep exact source boundaries: busy button ≥2200ms, form completion >1800ms, flash ≥140ms, transient status >4000ms. Page Tick count drives O Progress (+0.006), Editor (10 ticks), Grid commit (4 ticks), Task runner and Terminal; do not silently reinterpret every domain tick as elapsed time. PTY animations must either use proven deterministic scheduler control or checkpoint invariant stable completed/paused states paired with view-level exact intermediate frames.

Common expansion SC-FOCUS covers all 23 pages: capture every reachable focus stop in oracle order, one full forward and reverse cycle, then hover and press every rendered interactive target, including disabled rows and inert state samples. Split press/activation runs start fresh to avoid accumulating state. Capture disabled/inert hitboxes without asserting that a hover color must change. For menus/dialogs/pickers use the same expansion when open, including disabled options, gaps, borders and outside clicks. SC-RESIZE repeats a stateful representative per page at80→100→120→160→80 and immediately tests its retained focus/selection/cursor/scroll. This avoids redundant Cartesian products of every action and color while retaining all default color/size geometry, all meaningful actions at120×40, and narrow/wide stress cases listed in the TSV.
