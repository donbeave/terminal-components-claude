## Keyboard, pointer and ownership invariants

Global routing is too-small handling, top modal, open menu, attached/input owner, global chords, focused shell control, screen, fallback traversal/Escape. Preserve this actual ordering from `app.rs:507`; a generic global-hotkey-first dispatcher changes product behavior. Paste routes through the top modal before the underlying page (`app.rs:480`). Menus and modals capture keyboard and wheel; dismissal restores the previous owner and ring. Facts dialogs with acknowledgements consume outside clicks (`app.rs:1400`).

The shell uses F10/F1, Ctrl+Q/Ctrl+C/Ctrl+G/Ctrl+W, Alt+0–9, Tab/BackTab, menu/tab arrows and Enter. Finder query is typing-hot: q/j/k are text; query supports Ctrl+A, Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z, Ctrl/Alt+Backspace and Ctrl+U. Finder preview uses j/k/y and Escape, with printable query transfer governed by its handler. Ctrl+Up/Down changes scope. Alt+Enter opens alternatives; modifiers must preserve oracle behavior, including combinations currently tested.

Files uses Up/Down/PageUp/PageDown/Home/End, Enter/Right/Left/Backspace, Ctrl+H hidden, g jump, / preview search, y copy, a alternatives. Search mode additionally accepts editing keys and Alt+Enter. Disk uses arrows/tree keys, Space/a, s/f/r/x/c/d/p/y/t. Cleanup uses arrows/Home/End/Space/a/m/n/d/p/y; every modified-letter rejection matters. Plan review uses Space/u/c/p/Enter/x; executing plans use Enter/z/r/k/f/x, output navigation and control-specific keys. Trust/gates use arrows, scroll, y and Escape; arguments use Ctrl+S and concrete field editing. Activity uses i, s/r/x, digits for streams, / find, monitor Enter attachment, Ctrl+] or Ctrl+5 detach, stdin Enter/Ctrl+D/Ctrl+C and Escape. Text modals use Escape/Enter/q, arrows/j/k, PageUp/PageDown, Home/g and End/G. Exact guard ordering is source-authoritative; overlapping letters are not global shortcuts.

Mouse proof includes Move hover, Down pressed frame, Up activation, Secondary menu, DoubleClick activation, wheel routing and scrollbar press/drag. Derive coordinates from the **oracle's** captured hit rectangles; record literal cells and replay those same cells against candidate. Recomputing candidate hit positions would conceal changed hitboxes. Include one cell outside each edge, press inside/release outside, modal outside click, narrow drawers, menu/tab switching and status-copy targets. Use virtual 80 ms ticks for time-dependent click/pressed state. Batched and separated identical events must yield equal focus/hits/drafts/cursor.

Every scrollable surface needs top, middle, bottom, over-boundary wheel/key attempts, scroll thumb drag where supported, and hidden-edge fade frames. Selected/cursor list rows must not fade. Preserve exact glyph/style/cursor cells, clipping and wrap boundaries, including multi-cell Unicode and blank allocations. Finder split constant is body width 108 (`finder.rs:32`); test 100x30 and 120x40, plus boundary widths derived from shell margins. Do not infer the terminal breakpoint from the adjacent stale comment.
