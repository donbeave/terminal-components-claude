## Source defects and nonbinding assertions

These are text-level inconsistencies visible directly in the assigned sources; they are not newly verified production bugs:

- API 1075 says eight violations but table 1079–1087 has nine entries. API 1231 says 10 tested widgets/21 untested, table lists 14 and 1250 lists 17 untested. Core 1213 says four tested modules then lists six. API 987 says 24 raw-bg sites, list 988 contains 28; summary 1292 says 26. Preserve findings by identity, not contradictory totals.
- API 863 defines `Path = Vec<usize>` but 865/872/879 call this reorder-stable/correct identity. A vector of child positions does not identify a node after arbitrary sibling reorder. Preserve logical keys, not the audit's proposed positional Path fix.

- Research 1051's previous-frame latency is not blanket authorization for stale geometry after resize/disappearance. Follow later explicit layout/settling contract.
- Research 1076 requires every state on every component to differ; actual supported-state contracts must exclude impossible states with truthful reasons and verify claimed states. Research 1067 simultaneously says unnamed tokens remain identical and derived accent tokens change; distinguish explicitly derived tokens in the eventual assertion.
- API and app security amendments narrow broad “never rendered” claims. Masking, redacting Debug, raw-value lifetime, and deliberate persisted suffix disclosure require separate assertions. Do not revive `m` reveal or insist on synthetic suffix solely from the initial audit.
- Research's `cargo package --dry-run`, grep-based API enforcement, per-part rectangles, and example names are proposed tooling shapes. Verify actual supported commands and public API rather than prescribing historical sketches.
