## Authority and semantic checks

The runner process receives fixed public inputs, an output directory and narrow inherited observer pipes. It cannot select the private executable/source/configuration or manufacture the observer's in-memory events. The runner result must bind the protected context/run/operation, equal the exact private observation digests and reproduce the actual observed outputs. Requests with wrong source/tree/run, replay or unsupported fields fail. The reviewed imported sandbox denies private and ambient file reads except explicit runtime/source allowances, denies writes outside assigned output, and restricts process inspection, signals and network. No claim of another host platform is made.

The immutable index binds every child path/hash, schema, operation, lane, required membership and output identity. The positive sequence performs preflight, direct capture, PTY capture and closure; direct/PTY execute real fixture methods. Closure uses privately retained accepted report digests and checks completed files again. Missing/extra/swapped/foreign/replayed children, aliases, mutation between operations, failed members and changed completed output fail. The new child validator checks actual child schema and exact field set, not merely the member's declared schema.

Accounting archives actual committed assertion source. Test-body hashes and the non-test projection reject weakened assertions, outside-span changes, ignored tests and archive changes; approved replacement has a separately frozen digest. Full test results are source/package/target/profile/name-qualified. Future policies also bind owner and failure classification; closed records use complete identities. Preparation consumes independent authority before producer receipts exist; production cannot fall back to preparation because a receipt is absent. Candidate proposals cannot accept themselves, omit delivered identities or broaden policy.

TASK-008 rehearsal records bind the actual historical parent, independently constructed approved tree, original/patched assertion and production hashes, approved manifest, complete profile-qualified execution and derived statuses. Original and postpatch process evidence is preserved privately before publication. An approved assertion can expose an honestly failed future-owner diagnostic without making it parity success. Wrong parent/patch/tree, absent or forged pre/post evidence, changed derived register and incompatible assertion changes fail.

The sixteen-allocation and heavy-style perturbations execute real changed workloads. No-op, smoke-only, wrong denominator/counter owner, debug/parallel and disabled-strict cases fail. Candidate summaries are compared with private observations, not trusted as measurements. Actual production thresholds and hardware qualification remain TASK-067 obligations.
