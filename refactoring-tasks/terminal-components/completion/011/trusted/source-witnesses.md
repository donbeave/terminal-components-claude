- **P** means exact independently captured oracle cells/cursor/actions/visible state (CHK-002/004). **A** means the accepted architectural property and a real violating production mutation (CHK-005/006). A mixed row has both independent lanes, not a comparator derived from the candidate. Architecture-only APIs have no invented oracle widget.
- Every listed action is a separate ordered checkpoint: setup publication, action/update/settlement, first resulting draw, repeated draw without input, and the next changed-source publication. Later app/031/069 closure joins those exact consumer cases. A component capture cannot certify an application frame.

- State values are the explicitly listed alternatives and combinations in each row, not an arbitrary Cartesian product of unrelated flags. For any exposed paint part exercised by that row, expand Inherit, Clear, Set and an actual replacement slot at each declared override level; record exact Id/Family/Variant/Part/Resolved and whether cells came from component or caller row. The covered TextArea FIELD resolution-only exception applies solely to its named case. Disabled, read-only and inert registration behavior is observed separately from painted appearance.
- Event rows use all explicitly enumerated codes/modifier masks, not a representative mouse/key. Text rows use the listed literal strings and every UTF-8 split boundary; widths 0 through 120 are inclusive where specified. Collection keys A/B/C/D are distinct stable keys with identical visible labels where requested. Work rows count actual source reads, callbacks and allocations; a synthetic replacement loop cannot supply the counter.
- Each rejection in the observation column is an isolated real Rust mutation of the named source owner. It must compile and reach the branch before behavioral rejection counts. Examples include deleting the guard, routing through stale index, restoring the per-span loop or changing the exact arithmetic. A self-reported Boolean, source-string grep, case count or absent test identity is not execution proof. A missing source/branch mapping fails host preflight; no executor-selected applicability.
