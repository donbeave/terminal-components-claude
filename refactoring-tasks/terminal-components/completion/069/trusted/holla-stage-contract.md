## Three different ownership products

1. **Complete primary scenario.** The named repair task must pass every whole frame, cursor, event, source-native assertion and resized oracle assertion for the complete row. Parent checkpoints are never removed when ownership moves. Later concrete repair tasks044–049 close their newly assigned cross-route parents after all necessary producers are ancestors; this is not a blanket transfer to the validation-only050 task.
2. **Whole-checkpoint contribution.** The early task must pass every cell and cursor in a finite, nonempty selection of complete parent checkpoints. Source-only prefix/branch rules are materialized against the oracle once by TASK-003, with exact numeric checkpoint IDs and required minimum counts. Selection never occurs against candidate output. A prefix ends before its explicitly named foreign-surface event; that event and all following frames remain in the complete parent.
3. **Semantic contribution.** The independently qualified architecture operation exercises the exact source assertions/observations in the table using actual production handlers and protected schemas. It does not return a full-frame comparator pass. These checks cover, for example, usage-store persistence, emitted file targets, current-byte trust and first-running plan ownership while their downstream renderer is still unfinished.

For041–049, complete parents and whole-frame contributions use R-001 / AC-001 / CHK-004. Semantic contributions use R-001 / AC-008 / CHK-006, alongside R-002 / AC-002 on the same architecture check. The earlier shell032/040 mappings remain as separately documented: shell AC-001/CHK-006 and whole-frame AC-008/CHK-004.

## Fail-closed stage accounting

Every parent transcript still executes fully in the complete diagnostic sweep, with every actual mismatch and original/native test outcome retained. A contribution can close only its own immutable identity, never the parent. Previously closed contributions cannot regress. A missing contribution, failed minimum-count check, unsupported selector, unknown schema or changed future-owner map fails the early task. Neither an empty preservation intersection nor a contribution pass can substitute for the task's concrete required passing set.

TASK-003 freezes the contribution/action/assertion products; TASK-070 qualifies runner membership/extraction, TASK-071 qualifies independent accounting and TASK-072 qualifies semantic assertions.
