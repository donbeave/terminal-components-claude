# Single production style timing seam

This contract is normative for TASK-073 R-001/R-002/R-003. TASK-072 independently qualifies the probes and negative controls before accepting this foundation. TASK-067 consumes this same accepted seam for `style_resolve_share_of_frame_showcase_lists_120x40`; instrumentation qualification is not the final five-percent measurement.

Use stable Rust `std::time::Instant` and caller-owned testing-only aggregates scoped to one real production draw. The probe cannot be global/thread-local, retained in component semantic state, added to cache keys or consulted by rendering decisions. Scope restoration works on return and unwinding. Without the testing feature the probe and its branches are absent. With timing disabled, painting, semantic observations, style/cache query counts, cache contents and allocation counts are identical to the corresponding uninstrumented production path. A required public testing export may be added in `lib.rs`; no application-facing capability is widened.

Before candidate dispatch the independent host freezes a complete census of actual resolution entry boundaries reachable from the tested production draw, including `Ui::style`, `style_patched`, `style_defaults`, `style_inherited`, `paint_patch`, `resolve`, and the real color binding inside `surface_style` when reached. Include cache lookup/accumulation and binding work inside the appropriate entry interval. Wrappers such as `with_part` must not double-count an interval already measured by their leaf entry. Any direct Theme/bind call outside the census is a failing uncovered-path result, never implicitly zero. The independent source/call witness and invocation sequence must agree; candidate-provided counters alone cannot establish completeness. If an additional responsible file is required, assign it to this foundation before dispatch rather than installing a second seam in a later task.

Direct leaves are not limited to the Ui module. Pinned main `collection/rowui.rs:658` binds final nonempty CellUi styling; Lists120×40 has a94-column page and reaches this leaf12times. `components/status.rs:716` and `components/grid.rs:1979` bind nonempty deltas; their closed Lists zero-call branches and separate actual nonempty branch witnesses are explicit. Time only their existing bind expressions through the same caller-owned seam, not surrounding Drop alignment or painting. `ui/paint.rs` owns additional color-binding paint paths: census actual reached leaf binding or reject uncovered paths; never use whole `dim_layer` painting as numerator. These four responsible files are assigned to TASK073 before dispatch.

Run three fixed, interleaved modes against identical real production fixtures, inputs and warmed state:

1. Hooks disabled: time the whole production frame externally. This is the denominator workload, not an artificial enlarged loop.
2. Calibration: at every censused entry record an adjacent empty start/stop pair with the same bookkeeping and nesting policy; execute actual resolution outside that empty interval. All production work still executes.
3. Measured: record start, actual resolution, stop at every censused entry. This is the raw numerator. Do not sample or substitute a detached microbenchmark.

All three modes must produce the same cells, cursor, durable state, effects, cache outcome and invocation census. Independent qualification verifies every reachable branch, including empty/default/custom families, memo hits/misses, inherited styles and nested callbacks. Runtime clock values used for animation remain fixed while the independent benchmark clock measures execution duration.

Report raw numerator, matched calibration, corrected numerator, uninstrumented frame denominator, batch dispersion and the complete census separately. Corrected numerator is raw minus matched calibration; a negative differential is an invalid measurement and must never be clamped to zero. The host freezes compiler, optimization/profile, warmup, batch count/order, duration aggregation and measurement-error policy before candidate execution. It may not tune the policy after a failure. TASK-067 compares the upper bound of corrected numerator with the lower bound of the denominator and requires a ratio at most 0.05 under PERF_STRICT=1. A zero denominator, unresolved estimate or interval straddling 0.05 fails. The fixture denominator must contain exactly the specified production frame; unrelated work cannot dilute the ratio.

Independent negative controls must reject: omitted real resolution path; wrapper/leaf double counting; foreign or constant numerator; disabled-hook numerator reported as measured; skipped resolver in calibration; mismatched invocation membership/order; altered cells or semantic state; contaminated allocation/cache state; forged or inflated denominator; foreign calibration; negative corrected duration; changed benchmark policy; and uncertainty crossing the threshold. A deliberately expensive real resolution branch must increase the measured interval while an unrelated paint-only branch must increase only frame work. These controls execute actual mutated Rust paths, not a report-only truth table. Qualification may use deterministic injected clock readings for arithmetic/rejection tests, but final performance durations must come from the real benchmark clock.

Qualification separates instrument/protocol correctness from real measurement quality. Protected deterministic-clock control and recovery fixtures still execute the actual Rust App, every resolver and whole frame; their injected arithmetic durations are labeled and can never certify product performance. Separate mandatory actual `Instant` attestations execute ordinary, deliberately expensive real binding and paint-only source variants. The private judge retains every raw/calibration/corrected/denominator sample and reports `INVALID` for any negative correction, otherwise `REJECT` when the conservative upper ratio exceeds0.05, otherwise `PASS`. Source validity never predetermines a real timing pass. The submitted dispatcher must return the matching actual quality verdict; unknown host quality is neither swallowed nor retried/discarded to manufacture a pass. Freeze the quality algorithm and schedule before dispatch, not a fictional expected numeric wall-time result. Real cost causality is checked from the actual Instant attestations, never from injected clocks. TASK067 still requires a controlled-host valid real-clock measurement and the unchanged five-percent bound; accepting the qualification mechanism grants no performance waiver or application-facing clock selector.
